# Hockey Action Game

エアホッケーをベースにした爽快感のあるモバイルアクションゲーム

## 🎮 ゲーム概要

### ジャンル
縦持ちモバイルアクションゲーム

### 基本ルール
- エアホッケーのようにパック（コマ）を操作し、様々なオブジェクトを破壊する
- オブジェクトを破壊するとポイントを獲得
- 一定ポイントでパックが巨大化し、より大きなオブジェクトを破壊可能になる
- 制限時間内にどれだけ高いスコアを獲得できるかを競う

### 特徴
- 🎯 爽快感のある破壊アクション
- 📈 パックの成長によるパワーアップシステム
- 🚀 誘導ミサイルなどのスキルシステム
- 🏆 ハイスコアを目指すやり込み要素

## 🛠️ 技術仕様

### 開発環境
- **Unity Version**: 6000.0.42f1
- **Platform**: Mobile (Portrait)
- **Input System**: Unity Input System

### 主要コンポーネント
- **GameManager**: ゲーム全体の管理
- **PuckController**: パックの操作と物理演算
- **StageManager**: ステージとオブジェクトの管理
- **ScoreManager**: スコアシステム
- **GrowthManager**: パック成長システム
- **PlayerSkillManager**: スキルシステム
- **TimeManager**: 時間管理

## 🎯 主要機能

### コアゲームプレイ
- **パック操作**: 直感的なタッチ操作でパックを制御
- **物理演算**: リアルな衝突判定と物理挙動
- **オブジェクト破壊**: 様々なサイズのオブジェクトを破壊
- **成長システム**: スコアに応じてパックが巨大化

### スキルシステム
- **誘導ミサイル**: 自動で最も近い対象を攻撃
- **スキル強化**: 威力、発射数、クールダウンの改善
- **戦略的プレイ**: スキルの使い分けによる奥深いゲームプレイ

### UI/UX
- **リアルタイム表示**: スコア、残り時間、成長段階
- **スキル選択パネル**: 成長時のスキル選択
- **ゲームオーバー画面**: 結果表示とリスタート

## 🎮 操作方法

### 基本操作
- **パック移動**: 画面をタッチ・ドラッグしてパックを操作
- **オブジェクト破壊**: パックを当ててオブジェクトを破壊
- **スキル発動**: 自動発動（誘導ミサイル）

### ゲームの流れ
1. ゲーム開始
2. パックを操作してオブジェクトを破壊
3. スコア獲得でパックが成長
4. より大きなオブジェクトを破壊可能に
5. 制限時間内にハイスコアを目指す

## 🔧 開発・ビルド

### 必要な環境
- Unity 6000.0.42f1 以上
- Unity Input System パッケージ

1. Unity Hubで本プロジェクトを開く
2. 必要なパッケージが自動でインポートされることを確認
3. `Assets/Scenes/Main.unity` を開く
4. プレイボタンでゲーム開始
